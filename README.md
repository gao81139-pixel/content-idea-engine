# Content Idea Engine（内容灵感工程）

一个把“等待灵感”变成可重复流程的 Codex Skill。它从真实的观察、物品、产品、经历或记忆出发，通过结构化变形生成候选创意，再按受众价值、可执行性、战略匹配和安全性筛选。

## 它会做什么

- 每个新任务先完成固定十问，收集目标、受众、素材、资源、限制和判断指标。
- 使用“加、减、乘、除”扩展同一个创意种子。
- 使用“不可能优先”“属性反转”和“时间／角色／场景迁移”寻找反差与新视角。
- 组合两种以上方法，形成二阶创意。
- 输出创意矩阵、三张核心概念卡、五期系列规划、七天测试计划和决策阈值。
- 排除危险挑战、骚扰、未经同意的恶作剧、虚假冲突和不可核查的事实主张。

## 核心流程

`灵感碎片 → 结构化变形 → 反转／迁移 → 组合 → 筛选 → 测试`

## 安装

将本仓库克隆到个人 Codex Skills 目录：

```powershell
git clone https://github.com/gao81139-pixel/content-idea-engine.git "$env:USERPROFILE\.codex\skills\content-idea-engine"
```

本机创建版已经安装在 `$CODEX_HOME/skills/content-idea-engine`。

## 使用

在 Codex 中直接提出内容创意任务，或显式调用：

```text
使用 $content-idea-engine 为我的账号系统生成可拍摄的内容创意。
```

第一次响应会先提出十个问题；回答后才会生成方案。

## 来源与改进

本 Skill 根据用户提供的视频方法进行抽象和工程化，保留“加减乘除、反转、迁移”的创意框架，同时补充了十问信息门槛、量化筛选、验证计划以及安全与真实性约束。视频原文件不包含在仓库中。
